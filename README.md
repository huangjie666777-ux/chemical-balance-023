# 化学方程式配平与守恒核对工作台

基于 Vue 3 + TypeScript + Vite 的本地教学工具：录入反应物与生成物，
用精确整数/有理数运算求最简正整数系数，并逐元素（含电荷）核对守恒。
所有解析与求解均在浏览器本地完成，不发送任何网络请求。

## 输入语法

每种物质单独占一行：

- **元素符号**：大写字母开头，可跟一个小写字母，如 `H`、`Fe`、`Cl`。不在元素周期表中的符号会报“未知元素”。
- **下标**：正整数，写在元素或右括号之后，如 `H2O`、`O2`。`0` 与前导零（如 `H02`）均为非法下标。
- **多层圆括号**：如 `Ca3(PO4)2`、`Mg(OH)2`、`Ca3(Mg(CO3)2)2`，括号外的下标乘整个分组；空括号 `()` 报错。
- **结晶水（点号段）**：用 `.` 或 `·` 分隔，如 `CuSO4.5H2O`、`(NH4)2Fe(SO4)2.6H2O`。
  点号后的整数**只乘该段**（`5H2O` 即 10 个 H、5 个 O），不影响点号前的部分。
- **电荷**：写在整个物质末尾，格式为 `^符号` 或 `^数字符号`，如 `Na^+`、`SO4^2-`、`PO4^3-`。
- **电子**：写作 `e^-`，在离子半反应中作为普通物质参与电荷守恒。

解析错误（未知元素、空分组、非法下标、括号不匹配、电荷位置错误等）会直接指出是哪一侧的第几种物质及出错字符位置。

## 配平原理

1. 对每种物质统计每个元素的每分子原子数（递归乘以下标、括号下标与结晶水段乘数）及净电荷。
2. 以“反应物为正、生成物为负”建立齐次线性方程组，每个元素一行，离子反应再加一行电荷。
3. 用 bigint 分子/分母的精确有理数做高斯-约当消元求零空间，**全程无浮点运算**。
4. 零空间为一维且基向量各分量均为正时，乘分母最小公倍数、约去最大公约数，得到互质的最简正整数系数；严格保持用户录入的物质顺序，不增补、抵消或合并物质。

结果异常时分别说明：

- **无解**：守恒方程组只有零解，不存在非零系数；
- **必须出现零或负系数**：唯一解中某些物质系数为 0 或负数，不能作为配平系数（可能是物质放错了一侧）；
- **不唯一**：零空间维数大于 1（例如混入了多个独立反应），不擅自挑选一组系数。

## 核心操作

- 左右两栏分别录入反应物、生成物；每行可“添加 / 删除 / 上移 / 下移”。
- 点击 **配平** 按钮，或在任意输入框按 `Ctrl + Enter`（macOS 为 `⌘ + Enter`）。仅用键盘即可完成全部录入与配平。
- 结果区显示易读方程式（下标/上标排版，点号统一显示为 `·`）与守恒核对表：逐元素、逐物质展示“每分子数量 × 系数 = 贡献”及左右合计。
- **点击核对表中的元素（或“电荷”）**，方程式与表头中该元素会高亮，便于追查嵌套括号与结晶水段如何计数；再次点击取消。
- 点击 **复制纯文本方程式** 可复制如 `2H2 + O2 -> 2H2O` 的纯文本。
- 配平后若再修改输入（或存在解析失败），旧结果立即显示“已失效”警告且不再作为当前答案，需重新配平。
- 顶部提供四类一键示例：普通反应、嵌套分组、结晶水、带电子离子反应。

## 启动方式

需要 Node.js 18+（开发环境使用 Node.js 22）。依赖已安装时：

```bash
npm run dev -- --port 5173      # 开发服务器，仅监听 127.0.0.1
npm run build                   # 类型检查 + 生产构建（输出到 dist/）
npm run preview -- --port 4180  # 预览生产构建
npm test                        # 运行 Vitest 单元/组件测试
```

浏览器打开终端提示的地址（如 http://127.0.0.1:5173/ ）即可使用。

## 代码结构

- `src/lib/elements.ts`：已知元素符号表。
- `src/lib/fraction.ts`：bigint 精确有理数与 gcd/lcm。
- `src/lib/parser.ts`：递归下降化学式解析器、错误定位与元素 span 收集。
- `src/lib/solver.ts`：守恒矩阵、精确 RREF、零空间与最简整数解判定。
- `src/lib/render.ts`：化学式 token 化（下标/上标/点号）与纯文本输出。
- `src/App.vue`、`src/components/FormulaText.vue`：双栏录入、配平结果、守恒核对与高亮 UI。
- `src/**/*.test.ts`：解析器、求解器与工作台组件测试。
